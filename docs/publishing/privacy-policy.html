Pip – prompt helper: Privacy policy

Last updated: October 24, 2026

Pip is a browser extension that helps you write prompts for AI chat tools using context from the page you're on. Pip has no servers and no accounts. It does not collect, sell or share your data.

What Pip reads, and when

Pip reads page content only when you open its panel and choose a template. Depending on the template, that can be:

  • the text you selected, or the page's main text;
  • the page's URL and title;
  • console errors recorded on the page (the last 10, kept in memory on that page only);
  • the page's fonts and colors;
  • a screenshot of the visible part of the page;
  • the titles and URLs of your other open tabs;
  • the diff of a GitHub pull request you're viewing.

Before writing the prompt, Pip shows what it will include, and you can remove any of it. The finished prompt is only placed in a chat box on your screen or copied to your clipboard. Pip never sends a prompt anywhere, and never presses Enter for you.

What Pip stores

  • Settings and profile (whether Pip is shown, hidden sites, sleep delay, and the stack, preferences and test framework you choose to save) are kept in your browser's extension storage. If Chrome sync is on, Chrome syncs them across your signed-in browsers.
  • Game high scores are kept in local extension storage.
  • "Open in ChatGPT / Claude": while the new tab loads (15 minutes at most), the prompt you chose to send there is kept in local extension storage. It's deleted as soon as it's pasted or the tab is closed.

None of this leaves your browser except through Chrome's own sync of your settings.

Network requests

Pip makes one kind of network request: when you use the "Review this pull request" template on a GitHub pull request, it fetches that pull request's .diff file from GitHub. "Open in ChatGPT / Claude" opens those sites in a new tab, just as clicking a link would. Pip has no analytics, tracking or third-party services.

Removing your data

Uninstalling Pip deletes everything it stored. You can also clear your profile anytime in Pip's settings.
